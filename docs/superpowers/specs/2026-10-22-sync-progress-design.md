# 同步阶段进度

## 目标

同步进行中时，在任务列表和任务详情看到当前阶段。刷新页面后读取最新阶段。阶段只有三步：检查摘要、读取清单、复制镜像。不显示层数或字节，页面不自动刷新。

结束后仍使用现有状态：成功、无变化、失败。不额外保留一个「完成」阶段。

## 已确认的决定

- 阶段写入 `sync_task.progress_phase`。Web 和调度器继续只通过数据库交换任务状态。
- 阶段代码存在库里，中文文案只在 `service/sync` 定义一次，页面调用这套文案。
- 成功和无变化时清空阶段。失败时保留失败前所在的阶段。
- 进程启动时，把中断的同步标为失败，并保留当时的阶段。
- 编辑任务、切换定时检查都不修改该字段。
- 保存阶段失败时，这次同步记为失败，后续步骤不再执行。
- 不修改 `sync_log`。同步进行中时，列表和详情不再显示跳到同步记录的「同步详情」按钮。已结束的结果仍从侧栏「同步记录」查看。

## 数据

`sql/schema.sql` 的 `sync_task` 增加：

```sql
`progress_phase` varchar(16) NOT NULL DEFAULT '',
```

放在 `last_status` 之后。已有库由启动时的表结构同步补上这一列，默认空字符串。

取值：

| 代码 | 文案 | 含义 |
|---|---|---|
| `digest` | 检查摘要 | 正在比较源镜像摘要 |
| `manifest` | 读取清单 | 正在读取并整理要复制的清单 |
| `copy` | 复制镜像 | 正在向目标仓库推送 |
| 空字符串 | 不显示 | 当前没有进行中的阶段 |

常量名为 `PhaseDigest`、`PhaseManifest`、`PhaseCopy`。未知的非空代码按原样显示。

## 阶段怎么变化

1. 任务标成同步中时，同一次更新把 `progress_phase` 写成 `digest`。刷新后立刻能看到「检查摘要」。
2. `Run` 在调用 `Digest` 之前再次写成 `digest`。缺少目标登录信息、源镜像无法解析、目标引用无法生成时，`Run` 直接失败，不再改阶段。调度路径上阶段仍是第 1 步写下的 `digest`。
3. 摘要与上次不同后、调用 `Copy` 之前写成 `manifest`。
4. `Copy` 在清单处理完、真正推送之前通过回调发出 `copy`，由 `Run` 写成 `copy`。回调返回错误时，`Copy` 原样返回该错误并且不推送。`Run` 见到阶段写入失败时，结果说明只用「保存同步阶段失败」，不写入底层错误原文。
5. 摘要未变化时结果为无变化。不写 `manifest`，也不调用 `Copy`。
6. 结束写入：成功或无变化把 `progress_phase` 更新为空字符串。失败不更新该列。
7. 启动时重置仍在同步中的任务：`last_status` 改为失败，`progress_phase` 保持原值。

阶段写入使用这次同步的 context。写入失败时，`Run` 返回失败，说明固定为「保存同步阶段失败」，阶段停在上一次写成功的值。

## 代码边界

- `Engine.Copy` 增加 `progress func(phase string) error`。`Crane` 在 `Push` 之前调用它，参数为 `copy`。`progress` 为 nil 时跳过。
- `Run` 接收阶段写入函数。它负责 `digest` 和 `manifest`，并把 `Copy` 的 `copy` 回调转成同一次写入。
- 同步存储增加 `SetPhase(ctx, id, phase)`。调度器把 `Run` 的写入函数接到 `SetPhase`。
- `Finish` 只在成功和无变化时把阶段清成空字符串。
- 页面任务带上 `ProgressPhase`。阶段为空时，列表和详情不渲染阶段。有值时，列表在状态徽章下方显示文案，详情在「状态」下方增加「阶段」。
- 同步中时，列表和详情的操作区不渲染「同步详情」，也不渲染「立即同步」。编辑、启用或关闭、删除保持不变。

## 测试

- 无变化只记录 `digest`，不调用 `Copy`。
- 有变化按 `digest`、`manifest`、`copy` 的顺序记录。测试用的 `Copy` 先调用回调，回调成功后才计入一次复制。
- 任一次阶段写入失败时，结果为失败，说明是「保存同步阶段失败」，且不含底层错误原文。`digest` 写入失败时不调用 `Digest`。`manifest` 写入失败时不调用 `Copy`。`copy` 写入失败时不推送，也不计入复制。
- 成功和无变化的结束写入把阶段清成空字符串。失败的结束写入保留阶段。启动重置把状态改为失败并保留阶段。
- 列表和详情：同步中、失败且阶段有值时显示对应中文；阶段为空时不显示阶段；同步中的页面没有「同步详情」。
- 建表脚本包含 `progress_phase`，类型为 `varchar(16)`，默认空字符串。

## 不在本次范围

- 已复制层数、字节数或百分比。
- 页面自动刷新。
- 在同步记录中插入尚未结束的行。
- 只放在进程内存、不落库的进度。
